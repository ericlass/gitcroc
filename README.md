# gitcroc

[![CI](https://github.com/ericlass/gitcroc/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/ericlass/gitcroc/actions/workflows/ci.yml)

gitcroc is a cross-platform Git client (Windows, macOS, Linux) for projects that span many repositories. It has a Rust core, a Tauri 2 shell and a SolidJS UI, and works through the system `git` (2.40 or newer). It is in early development.

The specification in [`docs/spec/`](docs/spec/) is the source of truth. To learn how to run the checks, see [CONTRIBUTING.md](CONTRIBUTING.md).
